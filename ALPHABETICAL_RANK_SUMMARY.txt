===============================================
HOW IT WORKS
===============================================

Display Logic:
- All employees are sorted alphabetically by full_name (case-insensitive, A-Z)
- Each employee is assigned a rank based on their position in sorted array
- Rank = array index + 1 (so first employee = 1, second = 2, etc.)
- If employees are added/removed, ranks automatically adjust on next load

Example:
- Database has: Emp#5 "Zewdu", Emp#3 "Abebe", Emp#1 "Marta"
- Display shows: #1 "Abebe", #2 "Marta", #3 "Zewdu"

Sorting Code Added:
```javascript
employees.sort((a, b) => {
  const nameA = (a.full_name || '').toLowerCase();
  const nameB = (b.full_name || '').toLowerCase();
  return nameA.localeCompare(nameB);
});
```

Rank Display:
```javascript
employees.forEach((emp, index) => {
  const rank = index + 1;
  // render rank in first column
});
```
