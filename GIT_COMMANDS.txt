================================================================================
GIT COMMANDS TO PUSH TO GITHUB
================================================================================

Run these commands in the project folder: C:\Users\kenot\Desktop\Victorywater

STEP 1: Initialize Git Repository
----------------------------------
git init

STEP 2: Add All Files
----------------------
git add .

STEP 3: Create Initial Commit
------------------------------
git commit -m "Final: dynamic age, date toggle consistency, suspension_days fix, cleanup"

STEP 4: Add Remote Repository
------------------------------
git remote add origin https://github.com/kenotesfaye450/victory-hr-system.git

STEP 5: Rename Branch to Main
------------------------------
git branch -M main

STEP 6: Push to GitHub
----------------------
git push -u origin main

================================================================================
ALTERNATIVE: All Commands in One Block
================================================================================

Copy and paste all at once:

git init
git add .
git commit -m "Final: dynamic age, date toggle consistency, suspension_days fix, cleanup"
git remote add origin https://github.com/kenotesfaye450/victory-hr-system.git
git branch -M main
git push -u origin main

================================================================================
TROUBLESHOOTING
================================================================================

If you get "remote origin already exists":
  git remote remove origin
  git remote add origin https://github.com/kenotesfaye450/victory-hr-system.git

If you need to force push:
  git push -u origin main --force

If you need to configure Git user (first time):
  git config --global user.name "Your Name"
  git config --global user.email "your.email@example.com"

================================================================================
VERIFICATION
================================================================================

After pushing, verify on GitHub:
1. Go to: https://github.com/kenotesfaye450/victory-hr-system
2. Check that all files are present
3. README.md should display properly
4. .gitignore should be hiding unnecessary files
